# PRD — 「我的好友」关系页优化（对标探探）

> 状态：待评审（用户同意后方可开发）
> 范围：`xfjy-app/src/pages/mine/friends.vue` + 必要的后端小改动
> 关联：`01-需求文档.md` FR-USER-03（关系统计）、FR-USER-04（关系列表）、FR-USER-05（取消喜欢）、FR-USER-06（关注粉丝）

---

## 1. 现状与问题

4 个 Tab：互相关注(1) / 我喜欢(2) / 粉丝(3) / 谁看过我(4)。

| # | 现状 | 问题 |
|---|------|------|
| 1 | 顶部仅静态标题 | 后端 `GET /users/counts`（mutual/like/fans）已存在但前端未调用，用户看不到各关系数量 |
| 2 | 粉丝 Tab「喜欢 TA」按钮点击后仅 toast「已喜欢」 | 探探核心爽点缺失：如果对方也喜欢我，这正是一次**配对成功**，却无任何庆祝反馈，用户无感 |
| 3 | 「喜欢 TA」后按钮无状态变化 | 可重复点击、无已处理标记，列表不联动（应从「粉丝」转入「互相关注」） |
| 4 | 互相关注 / 已配对用户无「发消息」入口 | 关系建立后没有自然转化到聊天的通路，需用户自己再去消息页找 |
| 5 | 「谁看过我」列表行仅头像+昵称+性别年龄 | 无访问时间，信息价值低（探探显示「x 小时前看过你」） |
| 6 | 「我喜欢」列表无反馈线索 | 探探用「悄悄喜欢」（不暴露）+ VIP「谁喜欢我」制造付费点；本项目可先做低调版 |

## 2. 优化方案（参考探探）

### 2.1 顶部统计条（P0）

- 标题下方新增一栏：`互相关注 N · 我喜欢 N · 粉丝 N · 访客 N`，数据源 `getRelationCounts()`。
- 点击某项直接切换到对应 Tab（统计条与 Tab 联动）。
- 切 Tab 后刷新对应计数；「喜欢 TA」成功后 fans-1、（若成对）mutual+1，本地更新。
- 样式走 `var(--color-*)` 体系，选中项 `--color-primary`。

### 2.2 粉丝 Tab：喜欢即配对（P0，探探核心体验）

交互改为三态：

1. **未处理**：主色按钮「喜欢 TA」（现状保留）。
2. **喜欢成功且对方也喜欢我（配对成功）**：
   - 全屏庆祝反馈：居中弹出双方头像交叠 + 「配对成功！」+ 文案「你们互相喜欢，打个招呼吧」；
   - 弹窗内两个按钮：「打个招呼」（跳转聊天页 `/pages/chat/chat?id=`）、「继续逛逛」（关闭弹窗）；
   - 该行从粉丝列表移除，mutual 计数 +1。
3. **喜欢成功但未成对**：按钮变灰「已喜欢」，该行从粉丝列表移除（粉丝=尚未被我处理的用户），fans 计数 -1。

> 需后端支持：`POST /users/fans/{uid}` 返回体需能表达「是否配对成功」及对方信息。
> 现返回 `void` → 改为 `Result<MatchResultVO{matched: boolean, user: 简要用户信息}>`（§5 允许新增 Result<T> 接口形态，属存量接口返回体增强，不违反禁止清单）。

### 2.3 互相关注 Tab：直连聊天（P0）

- 列表行右侧增加「发消息」按钮（a11y-button，ghost，icon `i-ph-chat-circle-dots`），点击跳转 `/pages/chat/chat?id={uid}`。
- 与「进详情」并存：点行主体进详情，点按钮进聊天。

### 2.4 谁看过我：显示访问时间（P1）

- 列表行 meta 增加相对时间：「3 小时前看过你 / 昨天 / 3 天前」。
- 需后端 `GET /users/friends/4` 返回项增加 `visitTime` 字段（Mongo 访客记录本就有时间，属出参增强）。
- 相对时间格式化函数放 `utils/`（如已有则复用）。

### 2.5 我喜欢 Tab：低调状态提示（P2，可选）

- 若对方也喜欢我（已是互关），该用户其实应出现在互关 Tab；本 Tab 保持「取消喜欢」。
- 暂不做探探式「谁喜欢我」VIP 付费墙（涉支付与权限矩阵，另立需求）。

## 3. 非目标

- 不做「超级喜欢」、撤销滑动（已在匹配页移除，保持一致）。
- 不做 VIP 查看喜欢你的人（另立付费需求）。
- 不改关系数据模型（Mongo 喜欢/访客集合结构不动）。

## 4. 技术要点与约束

- 前端遵守 §7.1：按钮一律 `a11y-button`；颜色只用 `var(--color-*)`；图标 `i-ph-*`；热区 ≥88rpx；禁横向滚动。
- 后端改动仅两处出参/返回体增强，均在 `xfjy-server`（BFF 编排 + user-service 透传），不新增表、不新增持久化写入方（§3）。
- 接口契约：返回 `Result<T>`；分页沿用存量 `pagesize`（存量形态，不在本次整改范围）。
- 配对庆祝弹窗做成页面内组件（`components/match-celebrate.vue`），供后续匹配页复用。

## 6. 验收标准

1. 统计条数字与 `GET /users/counts` 一致，点击可切 Tab。
2. 在粉丝 Tab 喜欢一个「也喜欢我」的用户 → 弹配对庆祝 → 可直接进聊天；互关计数 +1、粉丝 -1。
3. 喜欢一个未互关粉丝 → 行移出列表、粉丝 -1，无庆祝弹窗。
4. 互关 Tab 每行可一键进聊天。
5. 访客列表显示相对访问时间。
6. `npm run build`（xfjy-app）与类型检查通过；`mvn -q -DskipTests compile`（改动模块）通过；§1–§8 校验命令无新增命中。
