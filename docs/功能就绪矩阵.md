1. 用户侧：申请并填入环信 IM 凭证（xfjy-message-service 的 client-id/secret）。

3. 运行 bash scripts/e2e-test.sh 跑通端到端冒烟。
4. 实跑 Spark 离线任务，确认推荐产出写入 MongoDB。
