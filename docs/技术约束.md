## 零、使用说明

### 0.1 约束等级

| 等级 | 含义 | 违反处理 |
|------|------|----------|
| `MUST` | 强制。违反即视为缺陷，阻断合并与发布 | PR 拒绝；已合并的按 P0 缺陷整改 |
| `SHOULD` | 推荐。除非有明确技术理由并在 PR 说明，否则应遵守 | 评审时质询，需记录豁免理由 |
| `MAY` | 可选。作为改进建议 | 不阻断 |

### 0.2 编号规则

```
CONST-<域>-<三位序号>
```

域取值：`VER`（版本）、`ARCH`（架构）、`API`（接口）、`DATA`（数据）、`SEC`（安全）、`PERF`（性能）、`DEPLOY`（部署）、`QA`（质量）。

### 0.3 现状标注

- `⚠️ 现状违反`：当前代码/配置不符合该约束，已列入整改清单。
- `✅ 现状符合`：当前已满足，需保持。
- 未标注：尚未核查或为新增约束。

## 一、版本矩阵

### CONST-VER-001 · 锁定 Java 侧版本组合 · MUST

以下版本构成一个**整体矩阵**，任何一项升级都必须整组评估，禁止单独升级某一个 BOM。

| 组件 | 锁定版本 | 说明 |
|------|----------|------|
| JDK | 25 | LTS，`maven.compiler.source/target` 统一在根 pom |
| Spring Boot | 4.1.1 | 父 POM，`spring-boot-starter-parent` |
| Spring Cloud | 2025.1.3 | 与 SB 4.1.x 配套 |
| Spring Cloud Alibaba | 2025.1.0.0 | Nacos 注册发现 |
| MyBatis-Plus | 3.5.17 | 必须用 `mybatis-plus-spring-boot4-starter`，分页插件单独引入 |
| Sa-Token | 1.46.0 | 必须用 `sa-token-spring-boot4-starter` |
| RocketMQ Spring Starter | 2.3.6 | — |
| Lombok | 以根 pom `${lombok.version}` 为准 | JDK 25 下会触发 `sun.misc.Unsafe` 弃用告警，属已知现象，不得通过降 JDK 规避 |

**校验方式**：
```powershell
mvn -q help:evaluate -Dexpression=project.parent.version -DforceStdout
Select-String -Path pom.xml -Pattern "java.version|spring-cloud.version|mybatis-plus.version|sa-token.version|rocketmq-spring.version"
```

**⚠️ 现状违反**：无版本矩阵注释，且构建日志已出现 Lombok 在 JDK 25 上的 `Unsafe` 弃用告警，缺少"整组升级"的书面约束。

### CONST-VER-002 · 禁止使用 SNAPSHOT 依赖 · MUST

除本项目自身模块（`${project.version}`）外，任何第三方依赖不得使用 `SNAPSHOT` / `RC` / `M` 版本。

**校验方式**：
```powershell
Select-String -Path */pom.xml -Pattern "SNAPSHOT|RC[0-9]|-M[0-9]"
# 预期：只匹配到本项目 version 1.0-SNAPSHOT
```

**✅ 现状符合**。

### CONST-VER-004 · uni-app 快照版本必须锁定并记录 · MUST

`@dcloudio/*` 使用日期快照版本（如 `3.0.0-5020620260917001`），不是语义化版本。要求：

1. `package.json` 中不得使用 `^` / `~` 前缀。
2. 升级时必须在 `docs/开发规范.md` 的升级记录中登记：升级日期、旧版本、新版本、验证清单。

**校验方式**：
```powershell
Select-String -Path xfjy-app/package.json -Pattern '"@dcloudio/.*": "\^|"@dcloudio/.*": "~'
# 预期：无输出
```

**⚠️ 现状违反**：需核查 `xfjy-app/package.json` 中 `@dcloudio/*` 是否带 `^`。

当前 `xfjy-admin` 使用 TypeScript 6.0.3，`xfjy-app` 使用 5.9.3，相差一个大版本。

Select-String -Path xfjy-admin/package.json,xfjy-app/package.json -Pattern '"typescript"'

**⚠️ 现状违反**：6.0.3 vs 5.9.3。

## 二、架构边界

### CONST-ARCH-001 · 调用链只允许三层 · MUST

允许的调用方向：

```
前端（admin / app）
   │  HTTPS
   ▼
xfjy-gateway（8090）
   │  lb://
   ▼
xfjy-server（18081，BFF）
   │  @HttpExchange / RestClient
   ▼
域服务（user / circle / video / match / message / pay / recommend / elasticsearch）
```

禁止：
- 前端直连域服务端口。
- 域服务反向调用 `xfjy-server`。
- 域服务之间横向直连（如需协作，经 BFF 编排或走 MQ）。
- 域服务调用 `xfjy-gateway`。

**校验方式**：
```powershell
# 域服务 pom 中不得出现 xfjy-server 依赖
Select-String -Path xfjy-*/pom.xml -Pattern "<artifactId>xfjy-server</artifactId>"
# 预期：只匹配 xfjy-server/pom.xml 自身
```

**⚠️ 现状违反**：`deploy/docker-compose.app.yml` 将 `18081~18090` 全部映射到宿主机，等于对外暴露了所有域服务端口。

---

### CONST-ARCH-002 · 域服务端口不得映射到宿主机 · MUST

生产编排中，只有 `xfjy-gateway`（8090）允许 `ports` 映射；其余后端服务只能通过 `xfjy-app-net` 内部网络访问。

**校验方式**：
```powershell
Select-String -Path deploy/docker-compose.app.yml -Pattern "^\s+- \"\d+:\d+\""
# 预期：只出现 "8090:8090"
```

**⚠️ 现状违反**：`18081~18090` 共 10 个端口映射到宿主机。

**整改建议**：删除域服务的 `ports`，本地调试改用 `docker compose exec` 或临时 override 文件。

---

### CONST-ARCH-003 · 服务间调用必须走注册发现 + 负载均衡 · MUST

禁止在代码中硬编码 `instances.get(0)` 式取实例。必须满足：

1. 使用 `spring-cloud-starter-loadbalancer` + `@LoadBalanced RestClient.Builder`，或
2. 自研拦截器必须实现轮询/随机 + 本地实例缓存 + 缓存 TTL。

**校验方式**：
```powershell
Select-String -Path xfjy-server/src/main/java -Pattern "instances\.get\(0\)|getInstances\("
# 预期：无输出，或仅出现在带缓存的负载均衡实现中
```

**⚠️ 现状违反**：`HttpServiceProxyConfig.ServiceInstanceInterceptor` 每次请求 `getInstances()` 后固定取 `instances.get(0)`，无轮询、无缓存、无超时、无重试。

---

### CONST-ARCH-004 · 每个数据存储只允许一个写服务 · MUST

数据归属见 `docs/需求文档.md` 6.1。核心规则：

- 一张 MySQL 表 / 一个 Mongo 集合 / 一个 ES 索引，**只能有一个服务执行写操作**。
- 其他服务读取必须经该服务的 API，不得直连数据库。
- 跨服务事务必须用最终一致性（MQ / 补偿），禁止分布式事务框架。

**校验方式**：
```powershell
# 检查是否有多个模块定义同名 Mapper
Get-ChildItem -Recurse -Filter "*Mapper.java" | Group-Object BaseName | Where-Object Count -gt 1
# 预期：无输出
```

**⚠️ 现状违反**：

| 冲突表 | 写入方 | 说明 |
|--------|--------|------|
| `tb_user` | `xfjy-sso` + `xfjy-server` | server 后台封禁/重置密码直写 |
| `tb_pay_order` | `xfjy-pay-service` + `xfjy-server` | server 定义了自己的 `PayOrderMapper` |
| `tb_vip_package` | `xfjy-pay-service` + `xfjy-server` | server 定义了自己的 `VipPackageMapper` |
| `tb_value_added_service` | `xfjy-pay-service` + `xfjy-server` | 同上 |
| Mongo 全库 `xfjy` | user / circle / video / match / recommend / elasticsearch | 共库，仅集合级隔离 |

**整改建议**：优先合并为「模块化单体」，或按服务拆 schema；`xfjy-server` 中的支付相关 Mapper 改为调用 `PayApi`。

---

### CONST-ARCH-005 · `xfjy-api` 只能放契约，不能放持久化实体 · MUST

`xfjy-api` 模块允许包含：
- `@HttpExchange` 接口定义
- 纯 DTO / VO / QueryParam
- 枚举

禁止包含：
- `@TableName` / `@TableField`（MyBatis-Plus 实体）
- `@Document` / `@Id`（Mongo 实体）
- 任何 `spring-data-*` / `mybatis-plus` 依赖

**校验方式**：
```powershell
Select-String -Path xfjy-api/src/main/java -Pattern "@TableName|@TableField|@Document|@Indexed"
# 预期：无输出
Select-String -Path xfjy-api/pom.xml -Pattern "spring-data-mongodb|mybatis-plus"
# 预期：无输出
```

**⚠️ 现状违反**：`xfjy-api` 同时依赖 `spring-data-mongodb` 与 `mybatis-plus-annotation`，`UserInfo` 带 `@TableField`/`@Document`。

---

### CONST-ARCH-006 · 网关是唯一鉴权透传点 · MUST

网关必须：
1. 校验 Token 有效性（或至少校验签名/存在性）。
2. 将 `X-User-Id` / `X-Admin-Id` 透传给下游。
3. 拒绝未带 Token 的受保护路径（白名单除外）。

**校验方式**：
```powershell
Get-ChildItem xfjy-gateway/src/main/java -Recurse -Filter "*.java" | Select-String -Pattern "GlobalFilter|GatewayFilter"
# 预期：存在鉴权过滤器
```

**⚠️ 现状违反**：网关只有 `CorsConfig` 与 `RateLimitGlobalFilter`，无鉴权过滤器；鉴权完全依赖下游 `xfjy-server`。

---

### CONST-ARCH-007 · 内部接口必须有内部身份标识 · SHOULD

域服务之间的调用应携带 `X-Internal-Token`（共享密钥，环境变量注入），域服务校验后才处理。

**⚠️ 现状违反**：域服务无任何鉴权。

---

### CONST-ARCH-008 · 禁止提交死配置 · SHOULD

`application.yml` 中引用的中间件（如 Qdrant、Neo4j）若未在部署编排中提供，必须：
1. 移除配置，或
2. 标注 `# 未启用` 并确保对应 Bean 不会启动失败。

**校验方式**：对照 `deploy/docker-compose.middleware.yml` 的 services 列表与各 `application.yml` 的 `host`/`uri` 配置。

**⚠️ 现状违反**：Qdrant、Neo4j 配置存在但中间件未部署。

---

### CONST-ARCH-009 · Python 子项目不得混入 Maven 构建 · MUST

`xfjy-spark` 已退役，不得出现在根 `pom.xml` 的 `<modules>` 中；若保留目录，必须有独立 `README.md` 说明状态。

**校验方式**：
```powershell
Select-String -Path pom.xml -Pattern "xfjy-spark"
# 预期：无输出
```

**✅ 现状符合**（不在 modules 中），但目录仍在，建议加退役说明。

## 三、API 契约

### CONST-API-001 · 路径命名规范 · MUST

| 类型 | 规范 | 示例 |
|------|------|------|
| 资源集合 | 复数名词 | `/admin/users`、`/movements` |
| 单个资源 | `/{id}` | `/admin/users/123` |
| 子资源 | `/{id}/{子资源复数}` | `/admin/users/123/chat-sessions` |
| 动作 | `POST /{资源}/{id}/{动词}` 或 `PUT` | `/admin/reports/1/handle`、`/admin/users/1/freeze` |
| 内部服务 | 服务前缀 | `/es/user/location` |

禁止：
- 动词出现在集合路径（`/getUserList`）。
- 大小写混用（统一 kebab-case）。
- 路径带 `.do` / `.action` 后缀。

**校验方式**：评审 `@RequestMapping` / `@GetMapping` 等注解。

---

### CONST-API-002 · 统一响应体 · MUST

所有对外接口（网关可达）必须返回统一结构：

```json
{
  "code": 200,
  "message": "ok",
  "data": {}
}
```

规则：
- `code`：业务码，成功固定 `200`；失败见 CONST-API-003。
- `message`：面向用户的中文提示，不得暴露堆栈、SQL、类名。
- `data`：业务数据，无数据时为 `null` 或 `{}`，不得省略字段语义。
- HTTP 状态码与 `code` 保持一致（成功 200，鉴权失败 401，越权 403，参数错误 400，服务端错误 500）。

**例外**：文件下载、SSE、Actuator 端点可不包装。

**校验方式**：
```powershell
# 检查 Controller 是否直接返回裸 Map/List/实体（无包装）
Select-String -Path xfjy-server/src/main/java/com/xfjy/server/controller/*.java -Pattern "ResponseEntity<(Map|List|[A-Z][a-zA-Z]*)>"
```

**⚠️ 现状违反**：无统一 `Result` 包装类，Controller 直接返回 `ResponseEntity<Map<String,Object>>` / `ResponseEntity<Void>`；`data` 层缺失，前端拦截器靠 `res.code !== undefined` 判断，实际大多数接口无 `code` 字段。

---

### CONST-API-003 · 错误码分段 · MUST

| 段 | 范围 | 含义 |
|----|------|------|
| 成功 | 200 | — |
| 通用错误 | 400 ~ 499 | 参数、鉴权、越权、限流 |
| 服务端错误 | 500 ~ 599 | 未捕获异常、依赖故障 |
| 业务错误 | 1000 ~ 9999 | 按域分段：1000 用户、2000 内容、3000 支付、4000 后台 |

要求：业务错误必须给出可定位的 `code` + 中文 `message`，禁止只用 500 兜底。

**⚠️ 现状违反**：全部错误走 HTTP 状态码，无业务错误码；`Admin*Controller` 中 `catch (Exception e) { return 500 }` 出现 109 次。

---

### CONST-API-004 · 必须存在全局异常处理器 · MUST

每个对外服务必须有 `@RestControllerAdvice`，统一处理：
- 参数校验异常（`MethodArgumentNotValidException`）
- 业务异常（自定义 `BizException`）
- 未捕获异常（`Exception`）
- 鉴权异常（Sa-Token `NotLoginException` / `NotRoleException`）

**校验方式**：
```powershell
Get-ChildItem -Recurse -Filter "*ExceptionHandler*.java"
# 预期：每个对外服务至少 1 个
```

**⚠️ 现状违反**：全仓库无全局异常处理器，仅 `MyMetaObjectHandler`（MyBatis 字段填充，非异常处理）。

---

### CONST-API-005 · 分页参数统一 · MUST

| 参数 | 类型 | 默认值 | 上限 |
|------|------|--------|------|
| `page` | int | 1 | — |
| `pageSize` | int | 10 | 100 |

响应结构：

```json
{ "list": [], "total": 0, "page": 1, "pageSize": 10 }
```

禁止使用 `pagesize` / `page_size` / `size` 等别名。

**校验方式**：
```powershell
Select-String -Path xfjy-server/src/main/java -Pattern "pagesize|page_size"
# 预期：无输出（存量接口逐步整改）
```

**⚠️ 现状违反**：C 端接口大量使用 `pagesize`（`/users/friends/{type}?page=&pagesize=`），后台使用 `pageSize`，命名不统一。

---

### CONST-API-006 · 时间格式统一 · MUST

- 传输格式：ISO 8601 带时区，或 `yyyy-MM-dd HH:mm:ss`（二选一，全局统一）。
- 时区：`Asia/Shanghai`。
- 禁止返回时间戳数字（毫秒/秒）作为唯一形式。
- 前端必须用统一工具函数格式化，禁止各页面重复实现。

**校验方式**：
```powershell
Select-String -Path xfjy-server/src/main/resources/application.yml -Pattern "date-format|time-zone"
```

**⚠️ 现状违反**：`xfjy-server/application.yml` 未配置 `spring.jackson.date-format` 与 `time-zone`；前端曾出现 3 处重复的时间格式化实现（已收敛到 `src/utils/format.ts`，但需固化为约束）。

---

### CONST-API-007 · 请求头约定 · MUST

| Header | 用途 | 示例 |
|--------|------|------|
| `Authorization` | 用户/管理员 Token | `Bearer <token>` |
| `X-Request-Id` | 链路追踪（网关生成） | UUID |
| `X-Internal-Token` | 内部服务调用凭证 | 环境变量注入 |
| `Content-Type` | 统一 `application/json;charset=UTF-8` | — |

**⚠️ 现状违反**：无 `X-Request-Id`、无 `X-Internal-Token`。

---

### CONST-API-008 · 接口必须幂等或明确非幂等 · SHOULD

- `GET` / `PUT` / `DELETE` 必须幂等。
- `POST` 若可能重复提交（下单、支付确认、举报），必须支持幂等键（`Idempotency-Key` 或业务唯一约束）。

**⚠️ 现状违反**：`POST /users/vip/order` 无幂等控制，重复点击可生成多笔订单。

---

### CONST-API-009 · 禁止在 URL 中传敏感信息 · MUST

Token、密码、手机号、身份证号不得出现在 Query String 或 Path 中。

**校验方式**：
```powershell
Select-String -Path xfjy-*/src/main/java -Pattern "\?.*(password|token|mobile)="
```

**✅ 现状符合**。

---

### CONST-API-010 · 接口变更必须向后兼容 · MUST

- 新增字段：允许，前端必须容忍未知字段。
- 删除/重命名字段：必须保留旧字段至少 1 个版本，并标记 `@Deprecated`。
- 修改字段类型：视为破坏性变更，必须新开版本路径（`/v2/...`）。

## 四、数据约束

### CONST-DATA-001 · 表命名与必备字段 · MUST

- 表名前缀 `tb_`（MyBatis-Plus 全局配置 `table-prefix: tb_`）。
- 必备字段：
  - `id` BIGINT 自增主键
  - `created` DATETIME 创建时间（自动填充）
  - `updated` DATETIME 更新时间（自动填充）
- 需要软删除的表必须有 `deleted` TINYINT 默认 0。

**校验方式**：
```powershell
Select-String -Path deploy/mysql/init/*.sql,scripts/*.sql -Pattern "CREATE TABLE"
# 逐表核对是否有 created/updated
```

**⚠️ 现状违反**：

| 问题 | 具体表现 |
|------|----------|
| 缺 `updated` | `tb_operation_log` 只有 `created`，无 `updated` |
| 版本化 SQL 与实际库漂移 | `tb_user_info.signature` / `height` 在实体 `UserInfo` 与 `scripts/seed_users.sql` 中使用，但 `deploy/mysql/init/02-schema.sql` 建表语句未包含 |
| 表结构分散在多文件 | `tb_user.status` / `freeze_reason`、`tb_settings.match_notification`、`tb_user_info.photo_album`、`tb_review.target_id` 由 `02-schema.sql` 末尾 `ALTER TABLE` 追加；`tb_agreement` 在 `03-agreement.sql`；`tb_faq` / `tb_feedback` 在 `scripts/init-kefu.sql`；`tb_user_device` 在 `04-user-device.sql` |

### CONST-DATA-002 · 字符集与排序规则 · MUST

- 字符集：`utf8mb4`
- 排序规则：`utf8mb4_general_ci`（或 `utf8mb4_0900_ai_ci`，全库统一）
- 连接串必须含 `characterEncoding=utf8mb4` 与 `serverTimezone=Asia/Shanghai`。

**校验方式**：
```powershell
Select-String -Path deploy/mysql/init/*.sql,scripts/*.sql -Pattern "CHARSET|COLLATE"
```

**⚠️ 现状违反**：库默认字符集是 `utf8mb4` / `utf8mb4_unicode_ci`（`01-init.sql`），但绝大多数业务表建表时显式写成 `CHARSET=utf8`（3 字节，不支持 emoji 与部分生僻字）。仅 `tb_sensitive_word`、`tb_value_added_service`、`tb_faq`、`tb_feedback`、`tb_agreement`、`tb_user_device` 为 `utf8mb4`。用户昵称、动态正文、评论含 emoji 时会写入失败或乱码。

## 五、安全约束

### CONST-SEC-001 · 所有受保护接口必须校验登录态 · MUST

除白名单（登录、注册、公告列表、健康检查）外，所有接口必须校验 Token，未登录返回 401。

**校验方式**：逐 Controller 核对是否有 `@SaIgnore` 误用；用无 Token 请求扫描全部 GET 接口。

**⚠️ 现状违反**：`xfjy-user-service`、`xfjy-circle-service`、`xfjy-video-service`、`xfjy-match-service`、`xfjy-message-service`、`xfjy-pay-service`、`xfjy-recommend`、`xfjy-elasticsearch` 均未引入 Sa-Token。

---

### CONST-SEC-002 · 后台接口必须校验角色 · MUST

所有 `/admin/**` 接口必须校验角色，越权返回 403。角色校验以 `@RequireRole` 为准，且必须与前端路由 `meta.roles` 一致。

**校验方式**：
```powershell
# 列出所有 Admin*Controller 类级注解
Select-String -Path xfjy-server/src/main/java/com/xfjy/server/controller/Admin*.java -Pattern "@RequireRole"
```

**⚠️ 现状违反**：部分 `Admin*Controller` 无类级 `@RequireRole`，仅靠方法内 `isSuperAdmin()` 判断；`AdminKefuController` 曾对 `feedback/reply` 加 `@RequireRole("ADMIN")` 导致 `OPERATOR` 403（已修复）。

---

### CONST-SEC-003 · 越权防护：资源归属校验 · MUST

任何"按 ID 操作资源"的接口必须校验资源属于当前登录用户，否则返回 403。

典型场景：查看/修改他人资料、查看他人订单、操作他人动态。

**校验方式**：逐接口检查是否有 `userId.equals(currentUserId)` 判断。

**⚠️ 现状违反**：需专项审计（`/users/vip/order/{orderNo}`、`/admin/users/{id}/chat-messages` 等）。

---

### CONST-SEC-004 · 密码存储 · MUST

- 用户密码：BCrypt（cost ≥ 10）或 Argon2。
- 管理员密码：迁移到 BCrypt，迁移期兼容 MD5 校验后自动升级。
- 禁止明文、禁止可逆加密、禁止固定盐 MD5。

**⚠️ 现状违反**：管理员使用无盐 MD5（已由 WuKongIM 替代环信 IM，历史环信密码派生 `MD5(userId + "_xfjy")` 已下线，但 MD5 存管理员密码仍待迁移 BCrypt）。

---

### CONST-SEC-005 · 敏感配置外置 · MUST

**开发/测试环境（当前阶段）**：所有微服务的 `application*.yml` 直接写明文值，禁止使用 `${VAR:default}` 占位符写法。中间件和数据部署在本地虚拟机（192.168.20.130/133），不需要安全性包装，把问题搞简单。

**生产环境（后续部署云服务器时启用）**：数据库密码、Redis 密码、AK/SK、第三方密钥必须通过环境变量注入，禁止出现在：
- `application.yml` 默认值（本地开发除外，且不得是生产值）
- 代码常量
- 前端打包产物
- Git 历史

**校验方式**：
```powershell
# 开发/测试环境：确认无 ${} 占位符残留
Select-String -Path xfjy-*/src/main/resources/application*.yml -Pattern '\$\{[^}]+\}'
# 预期：无输出

# 生产环境：确认无明文密码
Select-String -Path xfjy-*/src/main/resources/application*.yml -Pattern "password:\s*[^$]"
# 预期：仅 application-local.yml 允许，且不得为生产密码
git log -p --all -S "LTAI" -- "*.yml" "*.java"
```

**当前状态（2026-10-31）**：✅ 开发/测试环境已全部改为明文，零 `${}` 残留。

---

### CONST-SEC-006 · 日志脱敏 · MUST

日志中禁止出现：
- 明文密码、Token
- 完整手机号（必须掩码）
- 身份证、银行卡
- 第三方密钥

**校验方式**：
```powershell
Select-String -Path xfjy-*/src/main/java -Pattern "log\.(info|warn|error)\(.*(password|token|mobile)"
```

### CONST-SEC-007 · 文件上传校验 · MUST

上传接口必须校验：
- 扩展名白名单（图片：`jpg/jpeg/png/gif/webp`；视频：`mp4/mov`）
- MIME 类型
- 文件大小（图片 ≤ 10MB，视频 ≤ 100MB）
- 文件名重命名（禁止用原始文件名落盘）

**校验方式**：核对 `MinioClient` 上传方法与 `spring.servlet.multipart.max-file-size`。

**⚠️ 现状违反**：`xfjy-server` 配置 `max-file-size: 30MB`（视频 100MB 会被拒），且未找到扩展名/MIME 白名单校验。

---

### CONST-SEC-008 · 富文本必须 sanitize · MUST

公告、协议、FAQ 答案等富文本在渲染前必须经 `DOMPurify` 或后端白名单过滤，禁止直接 `v-html`。

**校验方式**：
```powershell
Select-String -Path xfjy-admin/src -Pattern "v-html"
```

**⚠️ 现状违反**：需核查 `notice/index.vue`、`agreement/index.vue` 的预览渲染方式。

---

### CONST-SEC-009 · 登录与敏感接口限流 · MUST

- 登录接口：同 IP 每分钟 ≤ 10 次，同账号每分钟 ≤ 5 次。
- 验证码发送：同手机号每分钟 ≤ 1 次，每日 ≤ 10 次。
- 举报/反馈提交：同用户每分钟 ≤ 5 次。

**校验方式**：核对 `RateLimitGlobalFilter` 的规则配置。

**⚠️ 现状违反**：网关有限流过滤器，但未见针对登录/验证码的细粒度规则。

---

### CONST-SEC-010 · CORS 必须收敛 · MUST

生产环境 `allowedOriginPatterns` 不得为 `*`，必须配置具体域名。

**校验方式**：
```powershell
Select-String -Path xfjy-gateway/src/main/resources/application.yml -Pattern "allowedOriginPatterns"
```

**⚠️ 现状违反**：网关 `allowedOriginPatterns: "*"` + `allowedMethods: "*"` + `allowedHeaders: "*"`。

---

### CONST-SEC-011 · Token 存储与失效 · SHOULD

- 后台 Token 当前存 `localStorage`，存在 XSS 窃取风险。
- 目标方案：`HttpOnly` + `Secure` + `SameSite=Strict` Cookie + CSRF Token。
- 过渡期要求：所有富文本 sanitize（CONST-SEC-008）+ 退出登录必须服务端注销 Token。

**⚠️ 现状违反**：`localStorage` 存储；退出登录已改为调用 `logoutApi()`（部分修复）。

---

### CONST-SEC-012 · 生产必须开启中间件鉴权 · MUST

- Nacos：`NACOS_AUTH_ENABLE=true` + Token + Identity。
- MySQL / Redis / MongoDB：必须设密码，禁止无密码暴露。
- MinIO：禁止匿名读写。

**校验方式**：核对 `deploy/.env` 与 `docker-compose.middleware.yml`。

**⚠️ 现状违反**：开发环境 Nacos 鉴权关闭（可接受）；需确认生产配置。

### CONST-DEPLOY-010 · 音视频与 IM 必须走 TLS/WSS · MUST

浏览器只在 **secure context**（HTTPS 或 `localhost`）下允许 `getUserMedia` 获取摄像头/麦克风；非 localhost 的 HTTP 页面会直接拒绝授权，通话无法发起。

- 对外页面必须 HTTPS；`LIVEKIT_URL` 必须为 `wss://`，不得使用 `ws://`。
- LiveKit 信令 7880 不直接暴露明文到公网，必须由反向代理（Nginx/Caddy）在 443 终止 TLS 后转发，或由 LiveKit 自身配置证书。
- WuKongIM 客户端连接同样应使用 `wss://`（5200 前置 TLS 代理），避免混合内容被浏览器拦截。
- 内网调试允许 `http://localhost`，但不得作为验收环境。

**校验方式**：
```powershell
Select-String -Path deploy/.env.example -Pattern "LIVEKIT_URL"
# 预期：值为 wss:// 开头
Get-ChildItem deploy -Recurse -Include *.yml,*.yaml | Select-String -Pattern "ws://"
# 预期：无输出
```

**⚠️ 现状违反**：`deploy/.env.example` 原为 `ws://192.168.20.133:7880`，H5 页面为 HTTP，通话必然失败；已改为 `wss://` 并在 `.env.example` 注明两种 TLS 落地方式，证书与反代尚未配置。
