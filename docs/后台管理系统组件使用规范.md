# 后台管理系统组件使用规范（xfjy-admin）

- 生效日期：2026-11-07
- 适用范围：`xfjy-admin/src/**`（Vue 3 + Element Plus）
- 定位：token 层（`--xfjy-*`、Element Plus 桥接）已有，本文只约束**组件怎么用**。
- 上位规则：`AGENTS.md` §7.2；冲突时以 `AGENTS.md` 为准。

## 0. 审计基线（2026-11-07，只读统计）

| 维度 | 基线数字 |
|---|---|
| `el-button` / 裸 `<button>` | 129 / 0 |
| `type` 分布 | primary 42、无 34、danger 23、success 20、warning 10 |
| `size` 分布 | small 66、默认 61、large 2（仅 404） |
| 修饰 | link 48、plain 1、round/circle 0 |
| `el-form` / `el-form-item` | 19 / 93（14 个文件） |
| `label-width` | 80px ×17、未写 ×2（SearchBar、login） |
| 必填实现 | rules 驱动；`el-form-item required`=0、手写星号=0 |
| 校验提示 | `inline-message`=0（全部默认 block） |
| 容器三件套（border+shadow+radius） | 13 处规则块 |
| `el-card` / 卡片嵌套 | 1 / 0 |

## 1. 按钮

### 1.1 层级（硬规则）

| 层级 | 用法 | 允许位置 |
|---|---|---|
| 主操作 | `type="primary"` | **一屏只允许 1 个**（页面级“新增/保存/提交/导出”选其一；表格行内 `link` 不计入该额度） |
| 次操作 | 不写 `type`（EP 默认按钮） | 页面工具栏、弹窗取消/辅助动作 |
| 危险操作 | `type="danger"` | 仅删除、封禁、强制下线等不可逆动作；批量危险操作也用它 |
| 轻量操作 | `link`（可叠加 `type` 表示语义） | **仅**表格行内操作列、弹窗/抽屉底部操作区；表单字段旁禁用 |
| 状态确认 | `type="success"` | 仅“通过/完成/启用成功”的确认动作，**禁止**当“新增”主操作 |

禁止：
- 同一屏出现 2 个及以上 `type="primary"`；
- 用 `success` 代替 `primary` 做主操作（存量 20 处，按第 5 节迁移）；
- 在表单、页头、工具栏用 `link`（存量 `user/detail.vue:66` 一处违规）；
- 用自定义 class 覆盖 `.el-button` 的边框/背景/高度（全站只允许 `login-btn`、`jump-btn` 两处品牌按钮，新增需登记）。

### 1.2 尺寸（全站一种）

- **只允许默认尺寸**（不写 `size`，EP 32px 高）。
- 禁止 `size="small"` 与 `size="large"`。
- 理由：① 与 EP 表单控件默认 32px 同高，工具栏/表单/弹窗不错位；② 表格行内改用 `link`（无边框，不依赖 24px 小按钮）；③ 32px 点击热区优于 24px。
- 唯一例外：`views/error/404.vue` 的 2 个 `size="large"`（独立错误页，无表单与工具栏），登记在案，不得扩散。

### 1.3 可执行检查

```bash
# 主操作唯一性：人工按页面复核（grep 只能列清单）
rg -n 'type="primary"' xfjy-admin/src/views --glob '*.vue'

# 尺寸违规应为 0（404 两处例外需排除）
rg -n 'el-button[^>]*size="(small|large)"' xfjy-admin/src --glob '*.vue' | rg -v 'error/404.vue'

# link 出现在表格行之外需人工确认
rg -n 'el-button[^>]*link' xfjy-admin/src/views --glob '*.vue'
```

## 2. 表单

- `label-width` **统一 80px**（中文标签最长 4 字 + 冒号，80px 可容纳；“最后活跃时间”等超长标签用 `el-form-item` 自定义 label 换行，不加大全局宽度）。
- `label-position` **统一默认 `right`**，禁止逐页改 `top/left`。
- `size` 统一默认（不写 `size`），禁止 `large`（`login` 存量将在迁移时去掉）。
- 必填**只用 `rules` 驱动**（`el-form :rules` + `el-form-item prop`），EP 自动渲染星号：
  - 禁止 `el-form-item required` 手写属性；
  - 禁止在 `label` 里手写 `*`；
  - 禁止用 `is-required` 覆盖。
- 校验提示**统一默认 block**（输入框下方），禁止 `inline-message`；错误文案统一“请输入/请选择 + 字段名”。
- 例外登记：
  - `components/SearchBar.vue`：检索条不设 `label-width`（无标签对齐需求）；
  - `views/login/index.vue`：品牌登录页 `size="large"` 保留，迁移时评估；
  - 无 `:rules` 的 6 个表单均为检索/可选字段（review、sensitive 导入、user/index×2、user/detail 资料编辑），新增必填字段必须补 rules。

### 可执行检查

```bash
# label-width 只允许 80px（SearchBar/login 例外）
rg -n '<el-form[^>]*label-width="(?!80px)' xfjy-admin/src --glob '*.vue' -P

# 手写星号/required 属性应为 0
rg -n 'el-form-item[^>]*\brequired\b|label="[^"]*\*' xfjy-admin/src --glob '*.vue'
```

## 3. 容器与边框

### 3.1 单层边框

- **一个区域只允许一层容器边框**：外层已有 `border` 的卡片/面板内部，禁止再出现带 `border + border-radius` 的“小卡片”。
- 卡片内部只用：背景色（`--xfjy-bg-hover` / `--xfjy-*-50`）、间距（`--xfjy-space-*`）分层。
- 列表行之间的 `border-bottom` 属于**分隔线**，不算容器边框，允许保留；但同一容器内不要再叠加 `border-left/right` 形成“框中框”。
- `el-card` 内部禁止再放 `el-card`；禁止用 `el-card` 只为一个按钮区做外壳（用间距 + `el-divider` 或标题即可）。
- 容器统一：`border-radius: var(--xfjy-radius-lg)`（卡片）/ `--xfjy-radius-md`（面板），阴影只用 `--xfjy-shadow-card`；**卡片内部禁止 hover 抬升与 shadow**。

### 3.2 禁止项

- 禁止纯装饰 `div`（无内容、只负责画线/画框）：用 `border-bottom`、`el-divider` 或间距表达。
- 禁止 `div` 套 `div` 只为了加边框：优先合并到父容器。
- 禁止在已有边框容器内再写 `box-shadow` 制造“浮起卡片”。

### 3.3 可执行检查

```bash
# 单条规则内同时出现 border + box-shadow + border-radius：人工判定是否为容器
rg -n -U 'border:[^;]+;[\s\S]{0,200}(box-shadow:[^;]+;[\s\S]{0,200})?border-radius:' xfjy-admin/src --glob '*.vue'

# 模板内 el-card 嵌套：应为 0
rg -n -U '<el-card[\s\S]{0,2000}<el-card' xfjy-admin/src --glob '*.vue'
```

## 6. 验证门禁

```bash
cd xfjy-admin
npm run build
npm run lint:style:gate
```

- 改动只允许落在模板属性与 `<style>` 内；不得改业务逻辑、接口调用、事件处理。
- 若布局变化影响 Playwright 视觉基线，必须在交付说明中列出页面与原因，**禁止未说明就重录基线**。
