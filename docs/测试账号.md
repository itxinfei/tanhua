## 二、开发万能验证码

开发环境未接入短信服务商，后端内置万能验证码，任意手机号均可用它通过校验。

| 项 | 值 |
|----|-----|
| 验证码 | `123456` |
| 常量名 | `DEV_MASTER_CODE` |
| 定义位置 | [`UserService.java`](xfjy-sso/src/main/java/com/xfjy/sso/service/UserService.java:36)、[`UsersService.java`](xfjy-server/src/main/java/com/xfjy/server/service/UsersService.java:71) |
| 适用场景 | 登录、换绑手机号 |
| Redis Key 前缀 | `XFJY_SSO_CODE_` |

**注意**：真实下发的验证码仍优先；万能验证码是与缓存验证码"或"的关系（`code.equals(cached) || DEV_MASTER_CODE.equals(code)`）。

## 安全清单

生产部署前必须完成：

- [ ] 修改后台 admin 密码（admin123 → 强密码）
- [ ] 关闭或更换 `DEV_MASTER_CODE` 万能验证码
- [ ] MySQL/Redis/MongoDB/Nacos/Neo4j/ES/Qdrant 全部启用认证并改强密码
- [ ] Gitea 管理员密码改强密码，Runner 令牌轮换

- [ ] 服务器 SSH 禁用密码登录，改用密钥
- [ ] 确认本文件与 `scripts/mytanhua.sql` 不进入生产代码包
