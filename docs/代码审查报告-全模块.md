## 三、跨模块共性问题

| 共性 | 影响模块 | 说明 |
|------|----------|------|
| 万能验证码硬编码 | server, sso | 开发阶段暂保留，上线前必须移除 |
| `XInternalTokenInterceptor` 未 trim token | user/video/match/pay 等 8 个模块 | 复制粘贴代码，配置含空格时鉴权失败 |
| Redis 数据库密码明文 | 全部后端模块 | 应环境变量注入 |
| `@HttpExchange` + `@PostMapping` 双注解 | 全部域服务 | 语义不一致，维护成本高 |

| 日志打印 Token 明文 | gateway, match, message 等 | Token 泄露到 ELK/Splunk |
| `tokens: -xfjy-internal-dev-token-change-in-prod` 格式歧义 | 全部模块 | YAML `-` 前缀在部分解析器报错 |
| `sendCode` 返回验证码明文 | sso | 后续易泄露到前端 |
| `Tools.jackson` 非标准包 | recommend | 运行时 ClassNotFoundException 风险 |
| pageSize 无上限校验 | 全部分页接口 | 恶意大值可 OOM |
| CORS 全域放行 + credentials | gateway | CSRF 越权风险 |
