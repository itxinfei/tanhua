## 一、产品概述

### 1.1 产品定位
心飞交友是一款面向年轻群体的**陌生人社交平台**（类似陌陌/探探），通过 LBS 地理位置、智能推荐算法和实时音视频互动，帮助用户发现附近有趣的人，建立社交连接。

### 1.2 目标用户
| 维度 | 描述 |
|------|------|
| 年龄 | 18-35 岁 |
| 场景 | 想拓展社交圈、结识附近新朋友的年轻用户 |
| 特征 | 移动端为主，注重颜值与兴趣匹配 |

### 1.3 核心价值
- **发现**：基于地理位置 + 协同过滤算法，精准推荐附近的人
- **互动**：圈子动态、小视频、即时聊天，多维度建立连接
- **匹配**：探花卡片左右滑动 + 陌生人问题，增加破冰趣味性

## 四、功能需求

### 4.1 用户账户模块

#### FR-AUTH-01 注册/登录（SSO 服务）
- **描述**：用户通过手机号 + 短信验证码完成注册或登录
- **规则**：
  - 新手机号自动注册并创建 `tb_user` 记录
  - 登录成功签发 JWT Token，后续请求通过 Header 携带
  - Token 校验由 `TokenInterceptor` 统一拦截（`@NoAuthorization` 注解标记免登录接口）

#### FR-USER-01 用户资料读取
- **接口**：`GET /users?userID=&huanxinID=`
- **描述**：查询用户资料（支持按用户 ID 或环信 ID 查询）
- **字段**：昵称、头像、性别、生日、城市、学历、婚姻状态、收入、行业、个性签名、照片列表

#### FR-USER-02 用户资料更新
- **接口**：`PUT /users`
- **描述**：更新当前登录用户资料，更新后清除用户缓存（`@CacheEvict`）

#### FR-USER-03 关系统计
- **接口**：`GET /users/counts`
- **描述**：统计互相喜欢数、喜欢数（我关注）、粉丝数

#### FR-USER-04 关系列表
- **接口**：`GET /users/friends/{type}?page=&pagesize=&nickname=`
- **type 定义**：1=互相关注，2=我关注，3=粉丝，4=谁看过我
- **支持**：按昵称模糊搜索、分页

#### FR-USER-05 取消喜欢
- **接口**：`DELETE /users/like/{uid}`

#### FR-USER-06 关注粉丝
- **接口**：`POST /users/fans/{uid}`

### 4.2 推荐交友模块

#### FR-REC-01 今日佳人
- **接口**：`GET /xfjy/todayBest`
- **描述**：返回系统为当前用户推荐的今日最佳匹配对象（基于推荐评分 + 缓存）
- **降级**：无推荐数据时返回默认推荐用户

#### FR-REC-02 推荐用户列表
- **接口**：`GET /xfjy/recommendation`
- **参数**：分页、性别筛选
- **描述**：分页展示推荐用户，数据源为 Spark 协同过滤计算结果

#### FR-REC-03 用户详情
- **接口**：`GET /xfjy/{id}/personalInfo`
- **描述**：查看推荐用户详细资料

#### FR-REC-04 陌生人问题
- **查询**：`GET /xfjy/strangerQuestions?userId=`
- **回复**：`POST /xfjy/strangerQuestions`（body: userId + reply）
- **描述**：查看对方设置的陌生人问题并回复，作为破冰互动

#### FR-REC-05 探花卡片
- **接口**：`GET /xfjy/cards`
- **描述**：返回一批推荐用户卡片（左右滑动交互的前端数据）

#### FR-REC-06 喜欢/不喜欢
- **喜欢**：`GET /xfjy/{id}/love` — 写入 user_like，双方互相喜欢则建立好友关系
- **不喜欢**：`GET /xfjy/{id}/unlove`

### 4.3 圈子动态模块

#### FR-MOV-01 发布动态
- **接口**：`POST /movements`
- **参数**：textContent（文字）、location（位置名）、longitude/latitude（经纬度）、imageContent（多图）
- **流程**：
  1. 图片上传至阿里云 OSS
  2. 动态数据写入 MongoDB（publish 集合）
  3. 写入个人相册（album 集合）
  4. 写入个人时间线（time_line 集合）
  5. 发送 RocketMQ 消息（topic: `xfjy-quanzi`，type=1）触发推荐评分

#### FR-MOV-02 好友动态列表
- **接口**：`GET /movements?page=&pagesize=`
- **描述**：查询当前用户关注的好友动态（时间线）

#### FR-MOV-03 推荐动态列表
- **接口**：`GET /movements/recommend?page=&pagesize=`
- **描述**：查询系统推荐的动态（基于推荐评分排序）

#### FR-MOV-04 动态详情
- **接口**：`GET /movements/{id}`
- **描述**：查询单条动态，同时发送浏览消息（type=2）计入推荐评分

#### FR-MOV-05 谁看过我
- **接口**：`GET /movements/visitors`
- **描述**：查询访问过当前用户主页的访客列表

#### FR-MOV-06 个人动态列表
- **接口**：`GET /movements/all?userId=&page=&pagesize=`
- **描述**：查询指定用户的所有动态（个人主页）

### 4.4 互动模块（点赞/评论/喜欢）

#### FR-ACT-01 动态点赞
- **点赞**：`GET /movements/{id}/like` — 返回最新点赞数，发送 type=3 消息
- **取消**：`GET /movements/{id}/dislike` — 发送 type=6 消息

#### FR-ACT-02 动态喜欢
- **喜欢**：`GET /movements/{id}/love` — 返回最新喜欢数，发送 type=4 消息
- **取消**：`GET /movements/{id}/unlove` — 发送 type=7 消息

#### FR-ACT-03 评论列表
- **接口**：`GET /comments?movementId=&page=&pagesize=`

#### FR-ACT-04 发表评论
- **接口**：`POST /comments`（body: movementId + comment）
- **流程**：写入 comment 集合 → 发送 type=5 消息（评分 10 分）

#### FR-ACT-05 评论点赞
- **点赞**：`GET /comments/{id}/like`
- **取消**：`GET /comments/{id}/dislike`

### 4.5 小视频模块

#### FR-VID-01 发布小视频
- **接口**：`POST /smallVideos`
- **参数**：videoThumbnail（封面图）、videoFile（视频文件）
- **流程**：上传 OSS → 写入 video 集合 → 发送 RocketMQ 消息（topic: `xfjy-video`）

#### FR-VID-02 视频列表
- **接口**：`GET /smallVideos?page=&pagesize=`
- **描述**：分页查询小视频流（基于推荐排序）

#### FR-VID-03 视频点赞
- **点赞**：`POST /smallVideos/{id}/like` → 发送视频点赞消息
- **取消**：`POST /smallVideos/{id}/dislike`

#### FR-VID-04 视频评论
- **列表**：`GET /smallVideos/{id}/comments?page=&pagesize=`
- **发表**：`POST /smallVideos/{id}/comments` → 发送视频评论消息

#### FR-VID-05 视频用户关注
- **关注**：`POST /smallVideos/{id}/userFocus`
- **取消**：`POST /smallVideos/{id}/userUnFocus`

### 4.6 即时通讯模块

#### FR-IM-01 环信账号获取
- **接口**：`GET /huanxin/user`
- **描述**：返回当前用户的环信账号（用户 ID）和密码（MD5(userId + "_xfjy")），前端用此登录环信 SDK

#### FR-IM-02 添加联系人
- **接口**：`POST /messages/contacts`（body: userId）
- **描述**：互相喜欢后添加为环信联系人

#### FR-IM-03 联系人列表
- **接口**：`GET /messages/contacts?page=&pagesize=&keyword=`
- **描述**：查询环信联系人列表，支持按关键词搜索

### 4.7 消息通知模块

| 接口 | 说明 |
|------|------|
| `GET /messages/likes` | 点赞消息列表 |
| `GET /messages/comments` | 评论消息列表 |
| `GET /messages/loves` | 喜欢消息列表 |
| `GET /messages/announcements` | 公告列表（免登录，Redis 缓存 1 小时） |

### 4.8 附近的人模块

#### FR-NEAR-01 位置上报
- **接口**：`POST /baidu/location`（body: longitude, latitude, addrStr）
- **流程**：server 接收 → 调用 ES 服务 `POST /es/user/location` → 写入 ES user_location 索引（geo_point 类型）

#### FR-NEAR-02 搜附近
- **接口**：`GET /xfjy/search?gender=&distance=`
- **参数**：gender（性别筛选，可选）、distance（距离，默认 2000 米）
- **流程**：从 ES 按当前用户坐标 + 距离范围搜索 → 过滤性别 → 返回附近用户列表

#### FR-NEAR-03 ES 位置服务（内部接口）
- **更新**：`POST /es/user/location` — 写入/更新用户位置
- **查询**：`GET /es/user/location/{userId}` — 查询指定用户位置
- **搜索**：`POST /es/user/location/list` — 按坐标+距离+分页搜索附近的人

### 4.9 个人设置模块

#### FR-SET-01 设置查询
- **接口**：`GET /users/settings`
- **返回**：陌生人问题、通知开关、黑名单

#### FR-SET-02 陌生人问题设置
- **接口**：`POST /users/questions`（body: content）

#### FR-SET-03 黑名单管理
- **列表**：`GET /users/blacklist?page=&pagesize=`
- **移除**：`DELETE /users/blacklist/{uid}`

#### FR-SET-04 通知设置
- **接口**：`POST /users/notifications/setting`
- **开关**：likeNotification（点赞通知）、pinglunNotification（评论通知）、gonggaoNotification（公告通知）

### 4.10 推荐引擎模块

#### FR-ENGINE-01 实时评分收集（xfjy-recommend）
- **输入**：RocketMQ 消息（topic: `xfjy-quanzi` / `xfjy-video`）
- **评分规则（圈子）**：

| 行为类型 | type | 评分 |
|----------|------|------|
| 发布动态 | 1 | 1~3 分（按文字长度）+ 图片数量加分 |
| 浏览动态 | 2 | +1 |
| 点赞 | 3 | +5 |
| 喜欢 | 4 | +8 |
| 评论 | 5 | +10 |
| 取消点赞 | 6 | -5 |
| 取消喜欢 | 7 | -8 |

- **存储**：按日分集合写入 MongoDB（`recommend_quanzi_yyyyMMdd` / `recommend_video_yyyyMMdd`）

#### FR-ENGINE-02 离线推荐计算（xfjy-spark）
- **算法**：ALS 协同过滤（MLlib）
- **任务**：
  - `SparkUserRecommend`：用户推荐（每日计算用户→推荐用户列表）
  - `SparkQunaZi`：圈子推荐（计算动态推荐评分）
  - `SparkVideo`：视频推荐（计算视频推荐评分）
  - `MLlibRecommend`：ALS 模型训练与预测
- **数据源**：MongoDB 评分集合（mongo-spark-connector 10.x）
- **产出**：写入 MongoDB `recommend_user` 集合，供今日佳人/推荐列表查询

#### FR-ENGINE-03 ID 生成（dubbo-service IdService）
- **方式**：Redis 自增 + Hashids 混淆
- **键**：`XFJY_HASH_ID_` / `XFJY_ID_`
- **用途**：生成动态、视频等业务 ID

## 五、非功能需求

### 5.1 性能
| 指标 | 要求 |
|------|------|
| 接口响应时间 | P95 < 500ms（缓存命中 < 50ms） |
| 推荐列表加载 | 首屏 < 1s |
| 消息消费延迟 | RocketMQ 消费延迟 < 2s |
| 并发能力 | 单服务支持 1000 QPS |

### 5.2 缓存策略
| 缓存 | TTL | 失效策略 |
|------|-----|----------|
| 用户资料（userInfo） | 1 小时 | 资料更新时 @CacheEvict 主动失效 |
| 公告列表（announcement） | 1 小时 | 按分页键缓存，自然过期 |

### 5.3 安全
- JWT Token 认证，TokenInterceptor 统一拦截
- 环信密码 MD5 加盐（`userId + "_xfjy"`）
- OSS 上传走服务端签名
- 敏感配置（AK/SK）独立 properties 文件，不入库

### 5.4 可靠性
- RocketMQ 消息持久化，消费者异常记录日志不丢失（at-least-once）
- MongoDB 副本集部署
- ES 位置数据可重建（从 MongoDB UserLocation 同步）

### 5.5 可扩展性
- 服务间 HTTP Service 接口解耦，可独立扩缩容
- 推荐评分按日分集合，避免单集合膨胀
- Spark 作业可水平扩展计算节点

### 8.3 数据迁移注意事项（升级遗留）

1. **MongoDB 集合名**：`tanhua_users` → `xfjy_users`，已有数据需执行 `db.tanhua_users.renameCollection("xfjy_users")`
2. **RocketMQ 主题**：`tanhua-quanzi` / `tanhua-video` → `xfjy-quanzi` / `xfjy-video`，需确认旧主题无未消费消息后清理
3. **Redis 键**：`TANHUA_HASH_ID_` / `TANHUA_ID_` → `XFJY_HASH_ID_` / `XFJY_ID_`，切换时需迁移或清空重建
