# 软删除改造任务分配（多 Agent 协作）

> **认领规则**：将任务状态改为「进行中-<你的agent名>」，完成后改为「已完成」。
> **背景**：用户要求 app 中用户删除数据不能物理删除，必须标记删除（软删除），数据保留可恢复。

---

## 软删除技术规范（所有任务统一遵循）

1. **字段**：pojo 已加 `private Boolean deleted = false;`（任务0已完成）
2. **删除操作**：`mongoTemplate.remove(...)` → `mongoTemplate.updateFirst/updateMulti(query, Update.update("deleted", true), Xxx.class)`
3. **查询过滤**：C 端查询条件追加 `Criteria.where("deleted").ne(true)`
   - `ne(true)` 同时匹配 `false` 和 `null`（旧数据无此字段），零迁移成本
4. **findById → findOne**：需过滤的方法将 `mongoTemplate.findById(oid, Xxx.class)` 改为 `mongoTemplate.findOne(Query.query(Criteria.where("_id").is(oid).and("deleted").ne(true)), Xxx.class)`
5. **管理端查询不加过滤**：`queryAllPublishList`、`queryAllCommentList`、`queryAllVideoList` 保持原样
6. **判断条件**：`DeleteResult.getDeletedCount() > 0` → `UpdateResult.getModifiedCount() > 0`
7. **import 变更**：`com.mongodb.client.result.DeleteResult` → `com.mongodb.client.result.UpdateResult`，新增 `import org.springframework.data.mongodb.core.query.Update;`
