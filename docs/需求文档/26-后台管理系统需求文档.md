> 版本：v1.0
> 更新日期：2026-11-03
> 适用范围：xfjy-admin（Vue 3 + Element Plus 后台管理系统）+ 后端管理 API
> 前置阅读：`01-需求文档.md`（FR-ID 基线）、`02-技术约束.md`（CONST-* 约束）、`04-用户限制矩阵.md`

## 一、文档目的

本文档定义心飞交友后台管理系统的完整需求，覆盖：

1. **界面调整**：好友列表页优化、资料编辑页交互重构
2. **组件复用**：用户列表项组件抽取与共享
3. **交互优化**：选项卡选择式表单、批量操作、搜索筛选
4. **后台对接**：用户资料管理 API、数据统计、内容审核、聊天记录

## 三、界面调整需求

### 3.1 好友列表页优化（C 端 xfjy-app）

**当前问题**：
- 列表项右侧操作按钮紧贴卡片右缘，与左侧头像留白不对称
- 列表区域底部被 H5 全局 tabbar 遮挡

**调整方案**：

| 项 | 现状 | 调整后 |
|----|------|--------|
| 列表项右侧留白 | 无 | 增加 `padding-right: 8rpx`，与左侧 `margin-left: 24rpx` 视觉平衡 |
| 列表区域高度 | `height: 100vh` | `height: calc(100vh - var(--window-bottom, 0px))` |
| 列表底部留白 | 无 | `padding-bottom: calc(var(--window-bottom, 0px) + 24rpx)` |
| 组件复用 | `user-list-item.vue` 已被 nearby/friends/blacklist 三页共用 | 保持，新增 `online` 在线状态点支持 |

**验收标准**：
- 好友列表页滚动时，最后一项完整可见不被 tabbar 遮挡
- 列表项左右留白视觉对称
- 在线用户头像右下角显示绿色状态点

### 3.2 资料编辑页重构（C 端 xfjy-app）

**当前问题**：
- 城市、身高、学历、行业使用 `uni.showModal` 弹窗输入，体验差
- 输入框无校验，可输入任意字符
- 无法快速选择常见值

**重构方案**：选项卡选择式

| 字段 | 原交互 | 新交互 | 选项来源 |
|------|--------|--------|----------|
| 昵称 | 弹窗输入 | 保留弹窗输入（自由文本） | — |
| 签名 | 弹窗输入 | 保留弹窗输入（自由文本） | — |
| 性别 | 选项卡（已有） | 保持 | 男/女 |
| 城市 | 弹窗输入 | **选项卡** | 12 个常见城市 + "其他" |
| 身高 | 弹窗输入 | **选项卡** | 150-190cm，间隔 5cm |
| 学历 | 弹窗输入 | **选项卡** | 高中/大专/本科/硕士/博士 |
| 行业 | 弹窗输入 | **选项卡** | IT/互联网、金融、教育、医疗等 12 项 |

**选项卡规格**：
- 单选，选中项高亮（品牌渐变背景 + 白色文字）
- 未选项：浅灰背景 + 深灰文字
- 选项间距：`gap: 16rpx`
- 触摸目标：`padding: 12rpx 28rpx`，高度 ≥88rpx
- 支持 `a11y-radio-group` 组件（键盘可达 + 读屏支持）

**验收标准**：
- 城市/身高/学历/行业字段显示为选项卡，点击即选中
- 选中项有视觉高亮
- 选项卡支持键盘操作（Tab 切换 + Enter 选中）
- 读屏朗读当前选中值

## 四、组件复用需求

### 4.1 用户列表项组件（`user-list-item.vue`）

**定位**：C 端通用用户列表行，支持头像、昵称、副信息、操作按钮、在线状态。

**Props 规范**：

| Prop | 类型 | 必填 | 说明 |
|------|------|------|------|
| `avatar` | `string` | 是 | 头像 URL（已过 `resolveAvatar`） |
| `nickname` | `string` | 否 | 昵称，空时显示"未设置昵称" |
| `meta` | `string` | 否 | 副信息纯文本（如"女 · 24岁 · 北京"） |
| `age` | `number \| string` | 否 | 年龄，非空时在昵称右侧渲染渐变胶囊 |
| `clickable` | `boolean` | 否 | 整行主体是否可点击进详情，默认 `false` |
| `online` | `boolean` | 否 | 是否在线（显示绿色状态点），默认 `false` |

**Slots**：

| 插槽 | 用途 |
|------|------|
| `#meta` | 自定义副信息（优先于 `meta` prop） |
| `#action` | 右侧操作按钮区 |

**Events**：

| 事件 | 触发条件 |
|------|----------|
| `tap-item` | 主体点击（仅 `clickable=true` 时触发） |

**使用页面**：

| 页面 | 路径 | 用途 |
|------|------|------|
| 附近的人 | `pages/match/nearby.vue` | 附近用户列表 + 喜欢按钮 |
| 好友关系 | `pages/mine/friends.vue` | 好友列表 + 取消喜欢/喜欢 TA |
| 黑名单 | `pages/mine/blacklist.vue` | 黑名单列表 + 移除按钮 |

### 4.2 后台用户详情抽屉（`xfjy-admin/src/views/user/detail.vue`）

**定位**：后台用户详情侧滑抽屉，Tab 切换展示基本信息、数据统计、照片墙、标签、聊天记录、内容、被举报记录、账号操作。

**已有 Tab 结构**：

| Tab | 名称 | 内容 |
|-----|------|------|
| `basic` | 基本信息 | 头像/昵称/性别/年龄/城市/学历/行业/收入/婚姻/注册/最后活跃/签名/封禁原因 |
| `stats` | 数据统计 | 动态数/粉丝数/关注数/匹配数/被举报数/VIP 等级 |
| `photos` | 照片墙 | 图片列表（预览） |
| `tags` | 个人标签 | 标签列表 |
| `chat` | 聊天记录 | 左侧会话列表 + 右侧聊天气泡 |
| `content` | 发送的图片和视频 | 动态/视频/评论子 Tab |
| `reports` | 被举报记录 | 举报列表（分页） |
| `actions` | 账号操作 | 封禁/解封/重置密码按钮 |

**新增需求**：

| Tab | 名称 | 内容 | 优先级 |
|-----|------|------|--------|

## 五、后台管理 API 需求

### 5.1 用户资料编辑 API

**场景**：客服代用户修改资料（用户反馈资料填写错误、头像不合规等）。

#### 5.1.1 编辑用户资料

```
PUT /admin/users/{id}/profile
```

**请求体**：

```json
{
  "nickname": "新昵称",
  "avatar": "https://minio.xfjy.com/avatar/xxx.jpg",
  "signature": "新签名",
  "gender": "man",
  "city": "北京",
  "height": "175",
  "education": "本科",
  "profession": "IT/互联网",
  "photoAlbum": "[\"url1\",\"url2\"]",
  "income": "10k-20k",
  "marriage": 0
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| `nickname` | `string` | 否 | 2-20 字符 |
| `avatar` | `string` | 否 | URL 格式 |
| `signature` | `string` | 否 | ≤50 字符 |
| `gender` | `string` | 否 | `man` / `woman` |
| `city` | `string` | 否 | ≤20 字符 |
| `height` | `string` | 否 | 100-250 数字 |
| `education` | `string` | 否 | 枚举：高中/大专/本科/硕士/博士 |
| `profession` | `string` | 否 | ≤20 字符 |
| `photoAlbum` | `string` | 否 | JSON 数组字符串，最多 6 张 |
| `income` | `string` | 否 | ≤20 字符 |
| `marriage` | `number` | 否 | 0-未婚 1-离异 2-丧偶 |

**响应**：

```json
{
  "code": 200,
  "message": "资料已更新",
  "data": null
}
```

**权限**：`SUPER_ADMIN` / `ADMIN`

**审计**：记录操作人、操作时间、变更前后值（见 §5.5）。

#### 5.1.2 获取用户资料编辑历史

```
GET /admin/users/{id}/profile-logs
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": 1,
        "operatorId": 1,
        "operatorName": "管理员A",
        "field": "nickname",
        "oldValue": "旧昵称",
        "newValue": "新昵称",
        "createdAt": "2026-11-03 10:00:00"
      }
    ],
    "total": 1
  }
}
```

| `page` | `number` | 是 | 页码 |

**响应**：

```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "userId": 2,

```

```
    → 调用 PUT /admin/users/{id}/profile

    → 失败提示 + 保留编辑状态
```

## 八、非功能需求

### 8.1 性能

| 指标 | 要求 |
|------|------|
| 用户列表加载 | ≤2s（1000 条数据） |
| 用户详情加载 | ≤1s |
| 资料保存响应 | ≤500ms |
| 批量操作响应 | ≤3s（100 条数据） |

### 8.2 安全

| 要求 | 说明 |
|------|------|
| 权限控制 | 所有管理接口校验 `SUPER_ADMIN` / `ADMIN` 权限 |
| 操作审计 | 资料编辑、封禁、退款等敏感操作记录审计日志 |
| 数据脱敏 | 日志中用户手机号脱敏显示 |
| 二次确认 | 封禁、退款、批量操作需二次确认 |

### 8.3 可用性

| 要求 | 说明 |
|------|------|
| 响应式 | 支持桌面端（≥1200px）和移动端（≤768px） |
| 错误提示 | 操作失败给出明确错误原因 |
| 加载状态 | 所有异步操作显示 loading |
| 空状态 | 无数据时显示友好空状态 |
