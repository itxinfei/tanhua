## 一、背景与目标

### 1.1 业务背景

当前圈子和视频仅一个 Tab（好友/推荐），无内容分级。用户进入圈子后无明确"看什么"目标，人均停留时间短。

### 1.2 数据目标

| 指标 | 当前 | 目标 |
|------|:---:|:---:|
| 人均使用时长（圈子+视频）| 3 min | 8 min+ |
| 人均每次访问 Tab 切换次数 | 0（没有 Tab）| 3+ 次 |
| 同城用户关注转化率 | — | 5%+ |

### 1.3 非目标

- 不在本版本实现基于内容标签的过滤（如只看"宠物"动态）
- 不做同城 Tab 的文字内容搜索（搜索留给后续专项）
- 不做热门榜运营人工排序干预（保底策略中的首日置顶除外）

### 1.4 依赖项与调用链

- **前置依赖**：FR-NEAR-01（位置上报 → Mongo + ES 双写）/ FR-NEAR-03（ES 位置服务，提供 POST /es/user/location/list 接口）
- **上游调用方**：运营后台（is_operator_pinned 置顶字段写入）
- **下游被依赖方**：无
- **数据流**：
  - 热门榜：用户行为 → RocketMQ → xfjy-recommend 评分 → 定时任务每 10min 重算 → GET /circle/feed?type=hot 返回排序结果
  - 同城 Tab：GET /circle/feed?type=city → xfjy-server 提取当前用户坐标 → POST /es/user/location/list（半径 50km）→ 按热度排序返回

### 3.3 热门分计算逻辑（后端）

```java
// 每次行为更新热度分值（定时任务每 10min 重新计算）
public double calculateHotScore(Feed feed) {
    double score = feed.getLikeCount() * 0.5 
                 + feed.getCommentCount() * 0.3 
                 + feed.getViewCount() * 0.2;
    // 时间衰减（阶梯函数，单位：小时）
    double timeDecay = calculateTimeDecay(feed.getPublishTime());
    return score * timeDecay;
}

// 时间衰减函数定义（阶梯函数）：
//   age <= 24h → 1.0
//   24h < age <= 48h → 0.5
//   48h < age <= 72h → 0.2
//   age > 72h → 0
// 冷启动期间（上线 1-7 天）窗口从 24h 扩展至 7 天时，衰减函数按同一阶梯缩放：
//   age <= 7d → 1.0；7d < age <= 14d → 0.5；14d < age <= 21d → 0.2；> 21d → 0
private double calculateTimeDecay(LocalDateTime publishTime) {
    long ageHours = ChronoUnit.HOURS.between(publishTime, LocalDateTime.now());
    if (ageHours <= 24) return 1.0;
    if (ageHours <= 48) return 0.5;
    if (ageHours <= 72) return 0.2;
    return 0.0;
}
```

### 3.4 冷启动策略

> 新上线阶段历史数据不足时，热门榜可能出现"空榜"或"内容过旧"问题。

| 阶段 | 策略 | 说明 |
|------|------|------|
| 上线首日 | 人工运营后台置顶 10 条精选内容 | 运营在 admin 端手动设置 `is_operator_pinned=true` |
| 上线 1-7 天 | 热门分计算窗口从 24h 扩展至 7 天，保底返回近 7 天互动 Top 20 | `GET /circle/feed?type=hot` 自动降级为 7 天窗口 |
| 上线 7 天后 | 恢复纯 24h 实时热门 + 时间衰减 | 正常逻辑 |

### 3.5 同城 Tab 兜底策略

| 场景 | 触发条件 | 处理方式 | 前端展示 |
|------|---------|---------|---------|
| 未授权位置 | 用户拒绝定位 | 展示引导卡片 + 一键授权按钮 | "开启位置权限查看同城内容" |
| 同城无内容 | ES 范围查询返回空 | 降级展示"热门" Tab 内容 + 提示 | "同城还没有人发布内容，为你推荐全站热门 🔥" |
| ES 服务不可用 | `POST /es/user/location/list` 响应超时 > 500ms 或返回 5xx | 降级为 MySQL 城市字段筛选（已有 addrStr），排序规则不变（仍按热度） | 静默降级，不提示用户 |
| 位置上报超 24h | `FR-NEAR-01` 上报时间 > 24h | 按用户资料城市字段保底筛选，排序规则不变 | 静默降级 |

## 四、边界场景

| 场景 | 处理 |
|------|------|
| 未授权位置权限点击"同城"| 弹权限请求弹窗，拒绝后 toast"无法查看同城内容" |
| "热门" Tab 无新热度内容 | 显示近 7 天热门（延长窗口至 7 天保底）|
| Feed 延迟加载（网络差）| 每个 Tab 独立 loading 骨架屏，不影响其他 Tab |
| VIP 专属权益 | "VIP 筛选"在同城 Tab 隐藏高级筛选选项（学历/收入）|

## 五、接口错误响应

> 本 PRD 接口错误统一走 FR-ENGINE-03 全局异常处理器，以下为业务侧特殊错误码：

| 接口 | HTTP | 错误码 | 场景 | 前端处理 |
|------|:---:|:---:|------|---------|
| `GET /circle/feed?type=hot` | 503 | `RECOMMEND_SERVICE_DOWN` | 推荐服务不可用 | 降级展示"推荐暂不可用" + 缓存数据 |
| `GET /circle/feed?type=city` | 403 | `LOCATION_DENIED` | 用户未授权位置 | 降级展示热门榜内容 + 引导授权卡片 |
| `GET /circle/feed?type=city` | 503 | `ES_SERVICE_DOWN` | ES 位置服务不可用 | 静默降级为 MySQL addrStr 城市字段筛选 |
| `GET /video/list?type=hot` | 503 | `RECOMMEND_SERVICE_DOWN` | 推荐服务不可用 | 降级展示"推荐暂不可用" |
