# 心飞交友（xfjy）模块命名说明

> 适用范围：后端 Maven 多模块、独立 Python 工程、两个前端工程。
> 结论先行：**`xfjy-spark` 与 Apache Spark 无关**；除历史命名外，其余模块命名均与其职责一致。本文档采用"文档澄清"而非直接重命名，避免破坏脚本、配置与路径引用。

## 一、命名总规则

| 前缀 / 规则 | 含义 |
|---|---|
| `xfjy` | "心飞交友"拼音首字母（Xin Fei Jiao You），同时是 Maven `groupId` 下的工程品牌名 |
| `xfjy-*`（模块目录） | 后端微服务 / 契约模块统一前缀 |
| `tb_`（数据表） | MyBatis-Plus 全局表前缀（`mybatis-plus.global-config.db-config.table-prefix=tb_`） |
| `xfjy-*`（容器名） | Docker 容器统一前缀，如 `xfjy-mysql`、`xfjy-minio` |
| `xfjy-net` / `xfjy-app-net` | 中间件网络 / 应用网络 |

## 三、独立 Python 工程：xfjy-spark（重点澄清）

| 项目 | 实际情况 |
|---|---|
| 目录名 | `xfjy-spark/` |
| 真实技术栈 | **Python 3.13 + PyTorch（torch>=2.0）+ pandas + scikit-learn + pymongo** |
| 是否在根 `pom.xml` | **否**，不属于 Maven 构建，独立运行 |
| 真实职责 | 权重共享对称双塔 + BPR 训练，产出 64 维用户向量，经纯 REST 灌入 Qdrant |
| 与 Apache Spark 关系 | **无任何关系**，不依赖 Spark、不提交 Spark 作业 |
| 为何保留现名 | 历史命名；重命名会影响 requirements、文档、脚本与路径引用，成本大于收益 |

后续若决定重命名，建议名：`xfjy-recommend-train` 或 `xfjy-ai-trainer`，并同步修改 `deploy/` 下引用、`docs/推荐引擎重构需求文档.md` 及 CI 脚本。

## 五、易混淆点清单

1. **xfjy-spark ≠ Apache Spark**：实为 Python PyTorch 双塔训练工程。
2. **xfjy-message-service ≠ 自研 IM 内核**：即时通讯核心能力由开源自建 WuKongIM（Apache-2.0，长连接+消息投递+离线消息）提供，音视频由 LiveKit SFU（Apache-2.0，WebRTC 转发）提供；本模块负责 token 签发与业务编排，原环信（Easemob）已完全替换下线。
3. **xfjy-server 与各业务服务**：`xfjy-server` 是面向运营后台的聚合服务，并非"唯一服务端"，业务能力分布在 11 个可部署微服务中。
4. **表名 `tb_` 前缀**：实体类不带 `tb_`，由 MyBatis-Plus 全局前缀自动拼接，写 SQL 时需带前缀。

## 七、新增子包清单（2026-10-31 P0 架构加固 + 推荐增强）

| 所属服务 | 新增子包 | 类 | 职责 |
|----------|----------|-----|------|
| xfjy-gateway | `filter/` | `InternalTokenFilter` | GlobalFilter，自动注入 `X-Internal-Token` |
| xfjy-server | `vector/` | `QdrantClient` | Qdrant HTTP 客户端（upsert / search / score），支持 enabled:false 降级 |
| xfjy-server | `graph/` | `Neo4jClient` | Neo4j Bolt 客户端（好友关系 CRUD / 二度好友 / 共同好友），支持 enabled:false 降级 |
| xfjy-server | `response/` | `Result<T>` | 统一响应体 `{code, message, data}` |
| xfjy-server | `exception/` | `GlobalExceptionHandler` / `BusinessException` | 全局异常处理 + 业务异常 |
| xfjy-server | `config/` | `HttpServiceProxyConfig` | `@LoadBalanced RestClient` + `lb://` 路由 + InternalToken 下发 |
| 8 个域服务 | `interceptor/` | `XInternalTokenInterceptor` | HandlerInterceptor，校验 `X-Internal-Token` |
| 8 个域服务 | `config/` | `WebMvcConfig` | WebMvcConfigurer，注册拦截器 |

> 8 个域服务 = user-service / circle-service / video-service / match-service / message-service / pay-service / recommend / elasticsearch
