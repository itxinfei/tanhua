## 二、功能需求

### 2.1 用户体系模块

#### FR-U-01 注册/登录（P0）
- **核心逻辑**：手机号 + 短信验证码一键注册/登录；新用户自动创建账号并引导完善资料；JWT Token 签发，有效期 7 天，支持续签
- **接口**：`POST /auth/login`（手机号+验证码）、`POST /auth/refresh`（Token 续签）

#### FR-U-02 个人资料（P0）
- **核心逻辑**：昵称、头像（OSS 上传）、性别、生日、城市、身高、学历、行业、收入、婚姻状态、个性签名、照片墙（最多 6 张）
- **资料完整度**：低于 60% 时弹窗引导补全（完整度影响推荐权重）

#### FR-U-03 实名认证（P1）
- **核心逻辑**：身份证二要素 + 百度 AI 人脸活体检测，认证通过后头像显示"已认证"角标，提升匹配信任度

#### FR-U-04 手机号绑定/换绑（P1）
- **核心逻辑**：旧手机号验证码校验 → 新手机号验证码绑定，保证账号安全

#### FR-U-05 注销账号（P0，合规必须）
- **核心逻辑**：二次确认 + 验证码校验 → 逻辑删除用户数据（保留 30 天可恢复期）→ 清除缓存/Token

### 2.2 核心社交模块

#### FR-S-01 卡片滑动匹配（P0，核心玩法）
- **核心逻辑**：
  - 推荐引擎产出候选列表（LBS 优先 + 协同过滤 + 资料完整度加权）
  - 右滑=喜欢，左滑=不喜欢，上滑=超级喜欢（VIP 专属）
  - 双方互相喜欢 → 匹配成功 → 弹窗提示 + 解锁聊天
  - 每日免费滑动次数限制（免费 50 次/天，VIP 无限）
- **接口**：`GET /match/cards`（获取候选卡片）、`POST /match/swipe`（上报滑动动作）

#### FR-S-02 今日佳人（P0）
- **核心逻辑**：每日推荐一位最佳匹配对象（综合评分最高），首页置顶卡片展示，Redis 缓存当日结果

#### FR-S-03 陌生人问题（P0）
- **核心逻辑**：用户预设 3 个破冰问题；匹配前可查看对方问题并回复；回复后解锁聊天（探探式破冰机制）

#### FR-S-04 附近的人（P0）
- **核心逻辑**：客户端定时上报 GPS 坐标 → 写入 ES geo_point 索引；搜索时按当前坐标 + 距离半径（1/3/5/10km）查询，支持性别筛选；距离越近排序越前

#### FR-S-05 即时通讯（P0）
- **核心逻辑**：基于环信 IM SDK；仅匹配成功后解锁聊天；支持文字/图片/语音/表情；已读回执、消息撤回（2 分钟内）
- **消息存储**：环信云端 + 本地 SQLite 缓存

#### FR-S-06 喜欢/粉丝/互相关注列表（P0）
- **核心逻辑**：type=1 互相关注 / 2 我喜欢 / 3 粉丝 / 4 谁看过我；支持昵称搜索；粉丝可反向喜欢促成匹配

### 2.3 圈子动态模块

#### FR-C-01 发布动态（P0）
- **核心逻辑**：文字（500 字内）+ 图片（最多 9 张，OSS 上传）+ 位置；可见范围：公开/仅好友；发布后异步写入时间线 + 发送 MQ 评分消息

#### FR-C-02 动态流（P0）
- **核心逻辑**：好友动态（时间线）+ 推荐动态（评分排序）双 Tab；下拉刷新 + 上拉分页加载；图片九宫格点击全屏预览

#### FR-C-03 互动（P0）
- **核心逻辑**：点赞（+5 评分）、喜欢（+8 评分）、评论（+10 评分）、取消（负评分）；互动行为通过 RocketMQ 异步计入推荐引擎

#### FR-C-04 个人主页动态（P1）
- **核心逻辑**：展示指定用户所有公开动态，相册模式浏览

### 2.4 小视频模块

#### FR-V-01 视频发布（P1）
- **核心逻辑**：视频（60 秒内）+ 封面图上传 OSS；写入 video 集合 + 发送 `xfjy-video` MQ 消息

#### FR-V-02 视频流（P1）
- **核心逻辑**：上下滑动切换视频（类抖音交互）；推荐排序（评分 + 时间衰减）；预加载下一视频

#### FR-V-03 视频互动（P1）
- **核心逻辑**：点赞/评论/关注作者，与动态互动复用评论体系

### 2.5 会员与商业化模块

#### FR-P-01 VIP 会员（P1）
- **核心逻辑**：月卡/季卡/年卡三档；支付渠道：微信支付 + 支付宝（uni-app 端原生支付）
- **VIP 权益**：

| 权益 | 免费用户 | VIP |
|------|----------|-----|
| 每日滑动次数 | 50 | 无限 |
| 超级喜欢 | 不可用 | 5 次/天 |
| 查看谁喜欢我 | 不可见 | 全部可见 |
| 位置穿越 | 不可用 | 任意城市 |
| 修改已滑动选择 | 不可用 | 撤销左滑 |
| 专属标识 | — | VIP 角标 |

#### FR-P-02 增值服务（P2）
- **核心逻辑**：超级喜欢单独购买（10 元/5 次）；曝光提升包（30 分钟内优先展示）；虚拟礼物（聊天中赠送，平台抽成 30%）

#### FR-P-03 支付系统（P1）
- **核心逻辑**：微信/支付宝双通道；订单表 + 支付回调验签；对账定时任务（T+1 核对）；退款流程

### 2.6 运营与安全模块

#### FR-O-01 内容审核（P0，合规必须）
- **核心逻辑**：
  - 图片：阿里云内容安全（涉黄/涉政/广告检测），机审 + 人审双通道
  - 文字：敏感词库（DFA 算法过滤）+ 阿里云文本审核
  - 视频：抽帧检测 + 人工抽检
  - 审核状态：待审核→通过/驳回，驳回原因通知用户

#### FR-O-02 风控系统（P0）
- **核心逻辑**：
  - 设备指纹（uni-app 端采集）+ IP 频率限制，防批量注册
  - 滑动频率异常检测（>200 次/小时标记可疑）
  - 举报系统：用户举报 → 人工审核 → 处罚（警告/禁言/封号）
  - 封禁设备 + 手机号黑名单

#### FR-O-03 举报与拉黑（P0）
- **核心逻辑**：举报类型（骚扰/欺诈/色情/冒充）；拉黑后双方不可见、不可聊天；黑名单管理

#### FR-O-04 运营后台（P1）
- **核心逻辑**：Vue3 + Element Plus 管理后台；用户管理（查询/封禁/解封）、内容审核工作台、举报处理、公告管理、数据看板（DAU/匹配率/付费转化）

#### FR-O-05 推送通知（P1）
- **核心逻辑**：uni-app Push（个推/极光）；触发场景：匹配成功、收到消息、被喜欢、系统公告；通知开关由用户设置控制

### 优先级总览

### 3.2 核心页面清单与设计说明

#### P-01 匹配页（卡片滑动首页）— TabBar 第 1 栏
- **布局**：
  - 顶部：城市定位选择器 + 筛选入口（性别/年龄/距离）
  - 中部：全屏卡片堆叠（最多 3 层，底层卡片缩放渐隐）
  - 底部：操作按钮组（左滑✕ / 超级喜欢★ / 右滑♥ / 撤销↩ / 加速⚡）
- **交互要点**：
  - 手势：左右滑动跟手位移，滑出阈值 1/3 屏宽触发动作；松手回弹动画
  - 卡片内容：主图全屏 + 底部渐变遮罩 + 昵称/年龄/距离/认证角标；点击卡片进入详情
  - 匹配成功：全屏弹窗（双方头像碰撞 + "It's a Match!"），按钮"发消息"/"继续滑动"
  - 滑动次数耗尽：弹出 VIP 引导弹窗
- **数据接口**：`GET /match/cards`

#### P-02 用户详情页 — 从匹配页卡片点击进入
- **布局**：
  - 顶部：照片轮播（swiper，指示器圆点，支持手势缩放）
  - 中部：基本资料卡（年龄/城市/身高/学历/行业/签名）+ 照片墙九宫格
  - 底部：陌生人问题区（折叠展开）+ 操作栏（喜欢/不喜欢）
- **交互要点**：照片左右滑动切换；下拉关闭详情；点击照片全屏预览
- **数据接口**：`GET /users/{id}/personalInfo`、`GET /users/{id}/strangerQuestions`

#### P-03 消息页 — TabBar 第 2 栏
- **布局**：
  - 顶部：搜索栏 + 通知图标（红点角标）
  - 通知入口横排：点赞 / 评论 / 喜欢 / 公告（图标+未读数）
  - 聊天列表：头像 + 昵称 + 最后消息 + 时间 + 未读角标
- **交互要点**：下拉刷新；左滑删除会话；点击通知入口进入对应列表页
- **数据接口**：`GET /messages/contacts`、`GET /messages/likes|comments|loves|announcements`

#### P-04 聊天页 — 从消息列表点击进入
- **布局**：
  - 顶部：返回 + 对方头像昵称 + 更多（拉黑/举报）
  - 中部：消息气泡列表（文字/图片/语音条），时间分割线
  - 底部：输入栏（文字输入框 + 表情 + 图片 + 语音切换）+ 发送按钮
- **交互要点**：长按消息弹出操作菜单（复制/撤回/删除）；语音按住说话松手发送；消息已读回执（双勾）；仅匹配成功可发送第一条
- **技术实现**：环信 uni-app SDK，本地 SQLite 离线消息缓存

#### P-05 圈子页 — TabBar 第 3 栏
- **布局**：
  - 顶部：双 Tab（好友 / 推荐）+ 发布按钮（右上角 + 号）
  - 列表：动态卡片（头像/昵称/时间/位置 + 文字 + 九宫格图 + 点赞/评论/喜欢计数）
- **交互要点**：Tab 切换无动画缓存滚动位置；图片九宫格点击全屏预览（支持保存）；点赞双击触发爱心动画
- **数据接口**：`GET /movements`、`GET /movements/recommend`

#### P-06 发布动态页
- **布局**：文字输入区（多行，500 字计数）+ 图片选择九宫格（+号添加，支持拖拽排序）+ 位置选择（高德 POI 列表）+ 可见范围开关
- **交互要点**：图片压缩后上传（uni.compressImage）；发布中显示进度；发布成功返回圈子页并刷新

#### P-07 视频页 — TabBar 第 4 栏
- **布局**：全屏竖屏视频播放器叠加信息层（右侧：头像/点赞/评论/分享按钮；底部：作者昵称/文案/位置）
- **交互要点**：上下滑动切换视频（swiper vertical）；双击点赞爱心动画；点击评论弹出半屏评论抽屉；首次进入提示"上下滑动切换"
- **数据接口**：`GET /smallVideos`、`POST /smallVideos/{id}/like`

#### P-08 个人中心页 — TabBar 第 5 栏
- **布局**：
  - 顶部：背景图 + 头像 + 昵称 + 认证角标 + ID + 资料（城市/年龄/签名）
  - 数据栏：动态数 / 关注数 / 粉丝数 / 获赞数
  - 功能入口列表：我的相册 / 谁看过我 / 我喜欢 / 粉丝 / 黑名单 / 设置 / VIP 会员（卡片样式突出）
- **交互要点**：点击头像进入资料编辑；VIP 入口常驻，未开通显示"开通会员"红色角标
- **数据接口**：`GET /users`、`GET /users/counts`

#### P-09 资料编辑页
- **布局**：表单分组（基本资料/照片墙/个人标签/联系方式）；每项右侧箭头进入二级编辑
- **交互要点**：头像/照片墙支持拍照或相册选择，裁剪后上传；资料完整度进度条实时更新

#### P-10 附近的人页 — 从匹配页筛选进入
- **布局**：地图模式（高德地图 + 用户头像标记点）+ 列表模式切换；距离筛选（1/3/5/10km）+ 性别筛选
- **交互要点**：地图标记点点击弹出用户迷你卡片；列表按距离升序排列；切换模式动画过渡
- **数据接口**：`GET /match/nearby?gender=&distance=`

#### P-11 登录页
- **布局**：品牌 Logo + 手机号输入框 + 验证码输入框 + 获取验证码按钮（60s 倒计时）+ 登录按钮 + 用户协议勾选
- **交互要点**：手机号格式校验；协议未勾选禁用登录；登录成功后判断资料完整度，低于 60% 跳转资料引导页

#### P-12 VIP 会员页
- **布局**：顶部权益轮播图 + 权益对比表（免费 vs VIP）+ 套餐选择卡（月卡/季卡/年卡，年卡标注"最划算"）+ 支付按钮
- **交互要点**：套餐选中高亮；点击支付弹出微信/支付宝选择；支付成功全屏庆祝动画 + 权益立即生效

#### P-13 设置页
- **布局**：列表分组（账号与安全：手机号/实名认证/注销账号；通知设置：点赞/评论/公告开关；隐私：位置可见范围/距离显示；通用：清除缓存/关于我们）
- **交互要点**：开关类设置即时生效（防抖 300ms 上报）；注销账号二次确认 + 验证码校验

#### P-14 运营后台（独立 Web 端）
- **布局**：左侧菜单栏（用户管理/内容审核/举报处理/公告管理/数据看板）+ 顶部面包屑 + 右侧内容区
- **技术**：Vue 3.5 + Element Plus 2.8 + ECharts 5.5
- **交互要点**：审核工作台支持批量通过/驳回；数据看板实时刷新（DAU/新增/匹配率/付费率曲线图）
