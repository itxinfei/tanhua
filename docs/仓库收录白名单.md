# 仓库收录白名单

> **白名单以 [`.gitignore`](../.gitignore) 为准，此文档只做说明。**
> 裁定日期：2026-11-03。原则：Gitee 只收录「必须的代码和必要的文件」，其余一律不入库。
> `.gitignore` 采用白名单写法：首行 `*` 忽略一切，随后逐条 `!` 放行；`!` 必须父目录在前。

## 一、必须入库（由 `.gitignore` 显式放行）

| 类别 | 路径 | 理由 |
|---|---|---|
| 后端/微服务源码 | `xfjy-*/src/**`、`xfjy-*/pom.xml` | 编译与运行的本体，缺一不可 |
| 模块说明 | `xfjy-*/README.md` | 模块职责与启动方式，协作者需要 |
| 根构建描述 | `pom.xml` | 聚合工程与依赖版本管理的入口 |
| 后台前端 | `xfjy-admin/src/**`、`public/**`、`index.html`、`package.json`、`package-lock.json`、`vite.config.ts`、`tsconfig*.json` | 源码、静态资源、构建配置，缺一不可 |
| 后台样式门禁 | `xfjy-admin/stylelint.config.mjs`、`stylelint-baseline.json`、`scripts/stylelint-gate.mjs` | 零 warning 基线与门禁脚本，CI 与全员共用 |
| 后台视觉回归 | `xfjy-admin/tests/visual/**`、`playwright.config.ts` | 基线图与用例随代码演进，需版本化比对 |
| 后台 ESLint / 环境 | `xfjy-admin/eslint.config.mjs`、`.env.development`、`.env.production`、`.env.e2e.example` | 公开构建配置，无密钥（真实密钥不入库） |
| App 前端 | `xfjy-app/src/**`、`index.html`、`package.json`、`package-lock.json`、`pnpm-lock.yaml`、`vite.config.mts`、`tsconfig.json`、`shims-uni.d.ts`、`uno.config.ts`、`eslint.config.mjs`、`stylelint.config.cjs`、`scripts/gen-icons.mjs` | 源码、类型声明、构建与图标生成配置 |
| 推荐训练 | `xfjy-recsys/README.md`、`requirements.txt`、`train/**` | 训练代码是数据链路的源；`output/` 模型产物不入库 |
| 部署 | `deploy/**` | compose、Dockerfile、MySQL 初始化 SQL、CI 构建脚本，缺一不可 |
| CI | `.gitea/workflows/**`、`.github/workflows/**` | 流水线与门禁定义 |
| 仓库级脚本 | `scripts/init-kefu.sql`、`scripts/init-push.sql`、`scripts/sync-agent-rules.ps1` | 初始化 SQL 与规则同步脚本，CI/全员复用 |
| 文档 | `docs/**` | 需求、技术约束、审查记录、导航 |
| 根级必要文件 | `README.md`、`AGENTS.md`、`CLAUDE.md`、`CHANGELOG.md`、`LICENSE`、`pom.xml`、`.gitignore`、`.gitattributes`、`.dockerignore`、`.env.example`、`.nvmrc` | 入口说明、版本记录、许可与仓库配置 |

## 二、禁止入库

| 类别 | 路径/示例 | 理由 |
|---|---|---|
| CLI 工具规则入口 | `.trae/`、`.cursor/`、`.windsurf/`、`.clinerules/`、`.roo/`、`.continue/`、`.junie/`、`.qoder/`、`.serena/`、`.joycode/`、`.github/copilot-instructions.md`、`.aider.conf.yml`、`GEMINI.md`、`CONVENTIONS.md` | 由 `scripts/sync-agent-rules.ps1` 从 `AGENTS.md` 生成，属个人工具环境；入库会造成多份真源分叉与仓库噪声 |
| AI 工具本地目录 | `.workbuddy/`、`.atomcode/`、`.playwright-cli/`、`.playwright-mcp/`、`.claude/board/` | 个人工作区与过程记录，非交付物 |
| 构建产物 | `node_modules/`、`dist/`、`target/`、`deploy/build/`、`*.tsbuildinfo`、`deploy/tmp_sync/` | 可重现生成，体积大 |
| 测试/截图产物 | `xfjy-admin/test-results/`、`xfjy-admin/playwright-report/`、`xfjy-admin/dashboard-desktop.png`、`xfjy-app/screenshot-*.png`、`_kefu*.png` | 验证过程产物，非源码；视觉基线例外（`tests/visual/**`） |
| 临时脚本与杂物 | `_*.js`/`_*.py`/`_*.txt`、`nul*`、`temp_*.json`、`xfjy-recsys/check_deps.py`、`xfjy-recsys/diag_pip.py` | 一次性诊断脚本，无复用价值 |
| 模型产物 | `xfjy-recsys/output/`（`model.pt`、`embeddings.json`、`meta.json`） | 训练输出，可由 `train/` 重现 |
| 敏感配置 | `**/minio.properties`、`**/application-local.yml`、真实 `.env`、`*.pem`、`*.p12`、`*.key`、`*.jks`、`*.keystore` | 含真实凭据；模板文件（`*.example`）可入库 |
| 本地测试凭证/素材 | 测试账号清单、`admin-login.json`、`test-assets/`、`test-img.jpg` | 含账号密码或体积大；本地保留即可 |
| IDE / 编辑器 | `.idea/`、`.vscode/`、`*.iml` | 个人 IDE 配置 |
| 日志与备份 | `*.log`、`*.bak`、`hist-*.txt`、`port-check.txt`、`verify.txt` | 过程文件 |

## 四、新增文件类型时的登记流程

1. 先确认该文件是「必须的代码或必要的文件」，能在他人环境重现构建/运行/验收。
2. 在 `.gitignore` 的对应分组（3–10）追加 `!父目录/` 与 `!具体文件`，父目录必须在前。
3. 跑 `git ls-files | git check-ignore --no-index --stdin`，必须无输出（确保已跟踪文件未被误忽略）。
4. 跑 `pwsh scripts/sync-agent-rules.ps1 -Check`，EXIT 必须为 0。
