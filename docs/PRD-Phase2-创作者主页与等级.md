## 一、背景与目标

### 1.1 业务背景

当前用户无法查看作者主页、无法追踪其全部作品、无法与创作者建立更深关系。优秀创作者没有成长激励，平台缺少 PGC（专业生成内容）生态。

### 1.2 数据目标

| 指标 | 当前 | 目标 |
|------|:---:|:---:|
| 内容消费者访问作者主页率 | 0% | 15%+ |
| 创作者 7 日回访率 | 40% | 60%+ |
| 创作者月均发布作品数 | 3.2 条 | 8+ 条 |
| 内容平均互动率（创作者粉丝 vs 非粉丝）| — | 粉丝 3x+ |

## 二、创作等级体系

### 2.1 等级设计

| 等级 | 图标 | 升级条件 | 权益 |
|:---:|:---:|------|------|
| Lv.1 新人 | ⭐ | 注册即送 | 基础曝光 |
| Lv.2 活跃 | ⭐⭐ | 粉丝 ≥ 10 + 发布 ≥ 3 条内容 | 内容加权推荐 + 可自定义主页背景 |
| Lv.3 人气 | ⭐⭐⭐ | 粉丝 ≥ 100 + 周更 ≥ 3 条 | 认证标识 + 主页推荐位 |
| Lv.4 达人 | 💎 | 粉丝 ≥ 1000 + 周更 ≥ 5 条 | 钻石认证 + 内容加热折扣 |
| Lv.5 明星 | 💎💎 | 运营邀请制 | 官方认证 + 流量保障 + 广告分成 |

> ⚠ **与积分等级的区别**：此处 `creator_level` 是内容创作等级（由粉丝数、发布频率决定），与用户积分体系的 `score_level`（由签到、任务等行为积分决定）**两者独立计算**。创作者主页展示 `creator_level`，积分页和等级进度条展示 `score_level`，前端上下文需明确区分，不可混淆。

### 4.2 获取创作者等级进度

- **接口**：`GET /users/{userId}/creator-level`
- **响应**：当前等级 + 下一等级条件差距

### 4.3 等级定时任务（每日 00:00 升级评估）

```java
@Scheduled(cron = "0 0 0 * * ?")
public void evaluateCreatorLevel() {
    // 查询所有达人级别以下用户
    List<Creator> candidates = creatorService.findUpgradeCandidates();
    for (Creator c : candidates) {
        int newLevel = calculateLevel(c.getFollowers(), c.getPosts(), c.getActiveDays());
        if (newLevel > c.getLevel()) {
            creatorService.upgrade(c.getUserId(), newLevel);
            pushService.push(c.getUserId(), "⭐ 恭喜升级到 Lv." + newLevel, PushType.LEVEL_UP, null);
        }
    }
}
```

## 五、边界场景

| 场景 | 处理 |
|------|------|
| 自己访问自己的创作者主页 | 显示"编辑封面"和"查看数据"入口，不显示"关注"按钮 |
| 被封禁/注销用户的创作者主页 | 展示"用户不存在"文案（普通用户无法访问）|
| 用户无作品也无动态 | 创作者主页展示"暂无内容"占位图 + 引发引导 |
| 等级升级瞬间 | 展示全屏庆祝动效 + 推送通知 + 升级弹窗 |
